| ADR-R-009 | ACCEPTED | `noa.deploy.release/1` is the public wire form of the deployment action bind: six required named members (`repository`, `commit`, `environment`, `imageDigest`, `targetAccount`, `operation`), closed-world, JCS-canonicalized to `paramsHash` with no domain tag, plus a normative display projection and two pinned projection identities. Consistent with ADR-R-004, it does not make `paramsHash` a universal cross-producer digest; it publishes the rule for one declared `action.canonical`. The roster is authenticated in `/1` by file discipline (owner other than the gate's uid, mode, link count, ancestor walk), a printed digest and an optional digest pin; a high-water state file refuses rollback. Decisions are checked against the gate's audience, the epoch and the sealed display's recipients in both modes; roster expiry, class and quorum in pinned mode. No fallback to the self-minted alpha root exists, and alpha keeps no display sealer. Reference configuration only: it is not wire language and carries no conformance claim (`NON-CLAIMS.md` §S8). | [docs/gate-pinned-trust.md](docs/gate-pinned-trust.md), `packages/gate/src/roster.ts`, `packages/gate/src/trust.ts` |
